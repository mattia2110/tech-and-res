# Global Warming - mitigation modifiers for the mod's climate harvest conditions
#
# Vanilla defines this family explicitly, and only for the 8 conditions it
# actually uses (00_modifier_types.txt:1868-2011): drought, flood, wildfire,
# extreme_winds, heatwave, disease_outbreak, earthquake, tsunami. Frost,
# hailstorm, locust_swarm and torrential_rains have no such modifier at all.
#
# That pattern implies the definitions file is what creates the modifier and the
# engine resolves it by name when applying a condition, so declaring them for new
# types should work the same way.
#
# NOT YET WIRED INTO ANY TECHNOLOGY OR LAW. Confirm in error.log that these
# resolve against the ztr_ conditions before using them for balance, otherwise
# the mitigation has to move into the intensity/duration blocks of each
# condition instead. The primary counterplay to the climate disasters remains
# reducing pollution, which is fully functional today.
